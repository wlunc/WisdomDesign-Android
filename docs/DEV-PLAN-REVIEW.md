## 4. Findings（3 条，**均非阻塞**）

### F-1 · medium · §14.3 两条契约命令的 **cwd 与相对路径矛盾**（按原文执行必失败）

- **位置**：`docs/DEV-PLAN.md` §14.3 M2 验收表第 ① 行与第 ⑤ 行（`:878`、`:882`；正文 `ls ../../contracts/*.yaml | wc -l`、`grep -c 'WD' ../../contracts/<组件>.yaml`、`grep -c 'WD' ../../contracts/icons.json`）
- **problem**：§14 开头（`:832`）明写"**所有命令都在 `android/` 下跑**"，但这两条用 `../../contracts/…`。从 `android/` 出发，`../../contracts` = **工作区根之外**（实测不存在，`ls: No such file or directory`）；而 §10.1 声明**组件契约属设计仓** `contracts/**` + manifest。⇒ 两处路径在任何解释下都不成立；**M0-5 契约落库后**，这是**批前签名冻结第 ① 条**的验收命令，按原文执行会得到 `No such file or directory`，开发者可能误判为"契约缺失"。
- **requiredFix**：① 把三处路径改为**从 `android/` 可达**的写法（按 §10.1 的设计仓归属 = `../wisdomdesign/contracts/…`；若最终落点在工作区根，则 = `../contracts/…`）——**先与架构师确认落点再定稿**；② 在 `§14.0` 补一句**cwd 与跨仓路径约定**（"本节命令 cwd = `android/`；跨仓路径以 `../<仓>/…` 书写"）；③ 建议在 `§12.2`/`§18.1` 的自检里加一条 `test -e <契约目录>` 守卫，让路径错误在 M0-5 当天就暴露。

### F-2 · medium · §12.1 的 **15 个 C-15 单元格反引号畸形** → 渲染吞字

- **位置**：`docs/DEV-PLAN.md` §12.1 表，"Android 形态 / C-15 名"列，**行 `:652`–`:686` 共 15 个单元格**（即带 `（← 旧名）` 标注的那些行，如 `WDTextField`/`WDSearchField`/`WDSwitch`/`WDRadio`/`WDProgressBar`/`WDProgressRing`/`WDDatePicker`/`WDAlert`/`WDBottomSheet`/`WDActionSheet`/`WDToast`/`WDTabBar`/`WDAssigneePicker` 等）
- **problem**：单元格写作 ``受控值 ``text`（← `value`）` → 契约名 ``text`` `` ——用**双反引号**包住一段**本身含单反引号**的内容。按 GFM 规则，双反引号跨度会被**后面第一个等长（双）反引号**闭合，实测渲染结果是：

  `受控值 ⟦code:text`（← `value`）` → 契约名 ⟧text``

  即 **"→ 契约名" 被吞进代码跨度**、末尾契约名掉到跨度外面并残留 `` `` ``。这正是"改过名的 14+1 行"的速查列（验收要求重点核对 C-15 的列），**渲染后难读、易误判哪个是契约名**（内容本身正确：`text`/`on`/`selection`/`value`/`date`/`presented` 等）。
- **requiredFix**：改用**单反引号**跨度并去掉内层反引号，例如：`` `text`（← `value`） → 契约名 `text` ``（或写成 `text（← value） → 契约名 text` 一把包住）。修完请用 `grep -nE '\`\`[^\`]*\`[^\`]*\`\`' docs/DEV-PLAN.md` 复跑一遍确认 = 0（**注意：`§0` 的 `` `07`/`08`… `` 那种"双反引号包多段单反引号"是合法写法，不计入**）。

### F-3 · low · 命令占位符 `<组件>` 无约定，且一处未加引号（会触发 shell 重定向）

- **位置**：`docs/DEV-PLAN.md` `:879`（`grep -c 'WD' ../../contracts/<组件>.yaml`）、`:780`（`--tests '*<组件>*'`，已加引号 ✓）、以及 `:628`/`:740`–`:745` 的**路径模板**（非命令）
- **problem**：全文用 `<组件>` 作占位符，但**没有一处说明"这是占位符、执行前替换"**；`:879` 的占位符**未加引号**，实测 `bash -c "grep -c 'WD' ../../contracts/<组件>.yaml"` → `bash: 组件: No such file or directory`（`<` 被当成**输入重定向**）。开发者原样粘贴会得到与"契约缺失"难以区分的报错。
- **requiredFix**：① 在 `§14.0`（或 `§4.0`）加一句占位约定："命令/路径模板中的 **`<组件>`/`<组件名>` 是占位符**，执行前替换为具体组件名；**路径模板不是命令**"；② `:879` 改为 `grep -c 'WD' "../../contracts/<组件>.yaml"`（加引号，避免重定向）；③ 顺带在 `§12.2` 自检里加一条 `grep -c '<组件>' …` 的**人工复核提示**（可选）。
